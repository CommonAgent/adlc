# Check the process rules

Part of code-critic. once the process document is read, to hold it to the process rules

## When to use this

once the process document is read, to hold it to the process rules

## What a good result looks like

Each problem at its line of the document: a phase that sends, posts, publishes, pays or signs with no person's yes before it; a gate whose document gives no reason; a line outside the extensions block; an extension line that changes the work; and every section 17.1 item the document fails. Beside them, which phases a person signs and which act in the world.

## When it comes back empty

A document with nothing against the rules says so. No model is called, so nothing is ever missing for want of one.

## How to do it

Nothing in this folder is run on its own; the offering names the one command that does the whole job, and this skill only explains what that command does for this step.

scripts/process-rules.mjs holds the document to the four tests of section 20.1, the approval levels of section 7, the acts in the world of section 21.3, the extensions rule of section 20.3 and conformance; scripts/process-review.mjs writes the result in this agent's own format and files it as the one piece.
