# Ask for a change

Part of usability-tester. Once a run has delivered, for an offering that takes changes.

## When to use this

Once a run has delivered, for an offering that takes changes.

## What a good result looks like

One change asked through the page's own call, and a new version back with the deliverable.

## When it comes back empty

An offering that declares no revisions and no steps is not asked, and that is a descriptor finding. A change with a price is not asked, because the tester never pays.

## How to do it

`askForChange` in scripts/trial.mjs.
